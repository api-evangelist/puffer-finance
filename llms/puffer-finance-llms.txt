# Puffer Finance

> Puffer Finance is an Ethereum infrastructure protocol building native liquid restaking (nLRP) integrated with EigenLayer, the UniFi based rollup, and Puffer Preconf preconfirmation services. Users stake ETH to mint pufETH and earn Ethereum staking plus restaking yields. Puffer is an onchain smart-contract protocol — integration is via its smart contracts, TypeScript SDK, and Rust CLI rather than a hosted web API.
